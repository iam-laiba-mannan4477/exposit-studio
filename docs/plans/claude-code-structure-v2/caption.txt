Claude Code ignored your rule? It's probably in the wrong file.

Where each one goes:
- CLAUDE.md: the project brief, loaded every session. Guidance, not a guarantee.
- CLAUDE.local.md: the same idea, but personal. Add it to .gitignore.
- .mcp.json: tools like GitHub or a database, for the whole team.
- .claude/settings.json: permissions, hooks, env vars, model. Enforced by the client.
- .claude/settings.local.json: your private override.
- rules/: instructions by topic, optionally scoped to file paths.
- skills/: reusable workflows, called with a slash or picked up automatically. commands/ is the older form.
- agents/: subagents with their own context and tools.
- hooks: scripts around tool calls; a pre-tool hook can block unsafe ones. Wired up in settings.json.

Three things to remember:
1. CLAUDE.md is guidance, not a guarantee.
2. If it must never happen, enforce it with a deny rule or a hook.
3. Start with CLAUDE.md and settings.json.
