# Example production: How an HTTP request reaches a Kubernetes app

These five files are the role outputs for the 60-second sample video.

- `facts.json` was researched and written by Claude during development, from the official AWS, Kubernetes and NGINX documentation listed in it.
- `strategy.json`, `script.json` and `board.json` were written by Claude acting as Creative Director, Storyteller and Visual Planner.

Nothing here is rendered in advance. When you choose "Create from example" in the studio, or run `python -m exposit.cli sample`,
the files are validated against the schemas, the same quality gates run as for a live production, and narration, rendering,
mixing and encoding all run on your machine.
